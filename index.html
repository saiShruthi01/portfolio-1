About

I started out building things — NLP pipelines, retrieval systems, and agents that reason through multi-step tasks — because I wanted to see AI actually ship and work at scale. Along the way, a quieter question kept surfacing underneath the technical architecture: not just whether a model works, but whether its output can still be trusted once the data it sees stops looking like the data it was built on.

That question is what's pulling me toward research now. I'm drawn to data-science methodology — how models can be evaluated for reliability and generalization when data are multilingual, spatially distributed, and constantly changing — and to applying that rigor to urban and environmental systems, where decisions genuinely depend on getting it right. I'm also learning Korean along the way, partly out of practical necessity, and partly because engaging properly with a research community means being able to sit in the room, not just read the papers.

Day to day, I still work like an engineer: Python, PyTorch, LLMs, LangGraph agents, and RAG pipelines over vector databases, making sense of messy real-world data. I'm just increasingly interested in pointing all of that at the harder methodological question — not only building systems that work, but establishing when and why their outputs can be trusted enough to act on.

Experience

Software Engineer · Oct 2024 – Present · Hyderabad, India

Built an NLP pipeline that processed 60,000+ multilingual commuter-feedback entries for Dubai's transport authority — language detection, translation, sentiment analysis, and named entity recognition with sentence transformers — and turned the output into a geospatial dashboard urban planners could actually use for decisions. Working across languages and locations made it clear how easily a model's output can drift once the data stops looking uniform.

Designed a production-grade agentic AI system in LangGraph that reasons through multi-step tasks, runs tools in parallel, and holds memory across a conversation across multiple LLM providers, plus a RAG pipeline on a Milvus vector database for semantic search over unstructured knowledge — supported by 50+ REST APIs. Small changes to memory and context reliably changed how the agent reasoned, which is what first got me asking how system design itself shapes model behavior.
